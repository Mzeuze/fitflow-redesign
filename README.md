- iOS UI: SwiftUI
- Web: React + TypeScript
- Main backend: Go
- Primary database: PostgreSQL
- Authentication: AWS Cognito
- AI/ML: Python + FastAPI
- Cache: Redis
- Real-time: WebSockets
