# Technology Stack Summary

| Layer | Selection | Reason |
|---|---|---|
| Mobile shared core | Kotlin Multiplatform | Reuse domain/data logic while retaining native APIs |
| Android UI | Jetpack Compose | Native Android UX and Health Connect access |
| iOS UI | SwiftUI | Native Apple UX and HealthKit integration |
| Web | React + TypeScript | Mature browser ecosystem and independent optimization |
| Main backend | Go | Concurrency, scalability and efficient runtime |
| Database | PostgreSQL | Transactions and relational health/fitness data |
| Auth | AWS Cognito | Managed OIDC/OAuth, MFA and federation |
| AI/ML | Python + FastAPI | Strong ML/computer-vision ecosystem |
| Cache | Redis | Low-latency hot data and ephemeral state |
| Real-time | WebSockets | Live social/challenge/progress events |
